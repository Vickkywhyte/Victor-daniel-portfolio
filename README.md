# victor-daniel-portfolio

Personal site for Victor Adegbe Daniel, AI engineer for financial crime compliance.
Live at https://victor-daniel-portfolio.vercel.app

## What is here
- `index.html` — the whole site. Single file, no build step. All images are embedded as data URIs, so it renders standalone.
- `victor.jpg` — portrait (kept for the social/OG preview image).
- `assets/` — source screenshots used on the page (also embedded in the HTML).
- `vercel.json` — security + caching headers.

## Deploy
Vercel auto-deploys the `main` branch. Push to `main` and the live site updates.
